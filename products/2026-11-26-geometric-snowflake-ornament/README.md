# Geometric Snowflake Ornament (2026-11-26)

Original design (no brands, characters, or real-world products). Draft only — nothing has been published or listed.

## Print profile — Snapmaker U1, 0.4 mm nozzle
- File: `snowflake-ornament.3mf` (mm, single part, 90 x 99 x 3.2 mm; build volume is 270 mm so ~6 fit per plate)
- Orientation: lay flat on the bed, **no supports, no brim needed**
- Layer height 0.20 mm (16 layers), first layer 0.20-0.25 mm
- Walls: every feature is a multiple of the 0.4 mm line width (arms/spokes 3.2 mm = 8 lines, outer ring 4.0 mm = 10 lines, hanging hole 4.8 mm)
- Perimeters 3-4, top/bottom layers 3-4, infill irrelevant (part is almost entirely walls); 100% infill is fine, only ~7.5 cm^3
- Suggested filaments: PLA / PLA+ in white, silk silver, or silk blue for a festive look; a color change at layer 1 or a multi-color tool setup is optional
- Estimated filament: ~9 g per ornament (PLA density 1.24 g/cm^3 x 7.5 cm^3)
