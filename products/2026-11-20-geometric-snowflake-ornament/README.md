# Geometric Snowflake Ornament (2026-11-20)

Original design (not based on any real product, brand or character). **DRAFT. Not published anywhere.**

## Files
- `geometric-snowflake-ornament.3mf`: print file (mm), Snapmaker U1 ready
- `geometric-snowflake-ornament.kerf.json`: editable Kerf source (variable `thick` = 3 mm)
- `preview-top.png`: render

## Model
- 74 x 94.5 x 3 mm, ~6.3 cm3, ~7.8 g PLA. Fits the U1's 270 x 270 x 270 mm volume with room for ~12 per plate.
- Prints flat, no supports, no brim needed.
- Smallest feature 4 mm wide stroke (10 extrusion lines at 0.4 mm). Hanging loop wall 3.25 mm, hole 4.5 mm (fits twine/ribbon/hook).

## Slicer settings (Snapmaker Orca, U1, 0.4 mm nozzle)
- Nozzle 0.4 mm (must match the printer profile), layer height 0.20 mm (15 layers)
- 3 walls, 3 top / 3 bottom layers, infill 15-20 % (part is nearly all walls)
- Supports off, PLA (white/ice-blue, or a silk/glitter PLA for sales photos)
- Multi-colour option: the U1 has 4 toolheads, so a colour change at layer 12-15 is easy to add for a two-tone look.

## Mesh note
Volume computed from the 3MF (6299.03 mm3) matches Kerf's solid volume exactly, so the mesh is closed. The flat top/bottom faces contain T-junctions from the CSG merge, which slicers accept. If a slicer warns, use its auto-repair.
