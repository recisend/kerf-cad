## Snapmaker U1 print settings (0.4 mm nozzle)
- Orientation: flat, as exported (Z = 0 to 3.0 mm; medallion 3.0 to 3.8 mm). No supports, no brim needed.
- Footprint 88.75 x 73.8 mm; fits the U1 bed (270 x 270 mm) easily; ~6 ornaments per plate in one batch.
- Layer height 0.2 mm (body = 15 layers; medallion = exactly 4 layers). Line width 0.42 mm.
- Walls: 3 (1.2 mm). Top/bottom 4 layers. Infill is irrelevant at this thickness; use 100% / solid.
- Two parts: assign `Snowflake Body` (white) and `Hub Medallion` (gold) to different toolheads in the slicer.
  Material = PLA; ~6.6 g total, ~15-25 min of print time (estimate; check in slicer).
- Minimum features (all >= 2 nozzle widths): twig width 3.0 mm, branch 3.5 mm, arm 4.5 mm,
  hang hole 3.0 mm with 1.5 mm wall. No overhangs.
- Threads: string/ribbon through the 3 mm hole.

## Mesh check
Signed volume 5201.46 mm3 matches Kerf. Mid-layer slices are fully closed. Top/bottom faces have
~180 tiny (<0.25 mm) unwelded T-junction edges at arm/branch joins; geometrically closed, slicers
handle these. Not test-printed: please slice-preview once before the first sale.
