## Snapmaker U1 / 0.4 mm nozzle print profile
- Size 94.8 x 91.5 x 100 mm (U1 volume 270^3) - ~74 g PLA (~60 cm3), single body.
- Print as exported (open end up). No supports, no brim needed (flat, large footprint).
- Walls 1.2 mm = exactly 3 perimeters at 0.4 mm line width; shared inner walls are also 1.2 mm.
- Floor 1.6 mm = 8 layers @ 0.2 mm. All heights are multiples of 0.2 mm (0.2 mm layer height, standard 0.4 mm nozzle profile).
- Suggested: 3 walls, 2-3 top/8 bottom layers, 10-15% infill (walls are solid anyway), PLA.
- Multicolour (U1 has 4 toolheads): easiest is a colour change per print; model is single-material as exported.
