## Snapmaker U1 / 0.4 mm nozzle print settings (suggested)
- Orient as modelled: flat base on bed, no rotation. No supports needed (all faces <= ~45 deg overhang; hex tunnels are point-up).
- Layer height 0.20 mm, first layer 0.20-0.25 mm
- Line width 0.42-0.45 mm; walls: 4 perimeters (about 1.7 mm); smallest wall in the design is 2.4 mm (honeycomb webs) = 5-6 perimeters
- Top/bottom: 5 layers (1.0 mm)
- Infill: 15-20% gyroid or cubic
- PLA / PETG; print about 215 C / 60 C for PLA (adjust to your filament profile)
- Phone slot is 14 mm wide (fits phones with typical cases); cable notch 16 mm wide in the front lip.
