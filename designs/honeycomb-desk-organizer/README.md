# Honeycomb Desk Organizer (original design)

Seven-cell hexagonal pen / tool / desk organizer. Original geometric design, not based on any real-world product, brand or character.

## Files
- `honeycomb-desk-organizer.3mf` – print file (mm), export from Kerf CAD
- `honeycomb-desk-organizer.kerf.json` – editable parametric source (open in Kerf web app)
- `honeycomb-organizer-iso.png`, `honeycomb-organizer-top.png` – renders

## Geometry
- Footprint 110.3 x 106.5 mm, tallest cell 104 mm (fits Snapmaker U1 270 x 270 x 270 mm with room for 4 per plate)
- Cell heights 64 / 84 / 104 mm (multiples of 0.2 mm layer height)
- Cell inner width 34.6 mm flat-to-flat
- Walls 1.6 mm (4 perimeters at 0.4 mm), floor 1.6 mm (8 layers at 0.2 mm)
- Flat base, vertical walls: no supports, no overhangs, no bridges
- Solid volume about 101 cm3 (~125 g PLA at 100% of modeled solid; real use is less with 2-3 perimeters + 15% infill on the base only)

## Snapmaker U1 / 0.4 mm nozzle settings
- Nozzle 0.4 mm, layer 0.2 mm (0.16 mm for finer finish), line width 0.42-0.45 mm
- Walls: 4 perimeters (1.6 mm), top/bottom layers: 5 / 8
- Infill: 10-15% gyroid (walls are almost all perimeter)
- Supports: off. Brim: 3-5 mm optional (tall narrow part)
- Orientation: as exported (Z up, base on bed)
- Multicolor: U1 has 4 toolheads; paint cells by height band (Orca/Snapmaker Orca) for a rainbow variant
- Seam: aligned/back, or random for a cleaner look on tall flat faces
