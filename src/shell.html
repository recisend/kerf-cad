      Working in Kerf

      Every feature is parametric: double-click it in the list to change it, drag the blue rollback bar to step back through history, and type expressions like #width / 2 + 3 mm into any value. Variables are features too.

      Fillet and chamfer work on straight edges between flat faces. Hole places one hole at each sketch point and drills into the material automatically. Export writes STL, 3MF, STEP, OBJ, GLB/glTF, FBX, Collada, USD, PLY, OFF, AMF, X3D and VRML. Exports from inside Claude arrive wrapped in a .zip.
