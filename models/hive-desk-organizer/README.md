# Hive Desk Organizer

Original, non-branded design: seven interlocking hexagonal cups at stepped heights (95 / 72 / 56 mm) for pens, brushes, tools or small plants. Not based on any real product, character or brand.

- **Size:** 108.4 x 104.6 x 95 mm (fits the Snapmaker U1's 270 mm build volume with room to spare)
- **Walls:** 1.6 mm (4 perimeters at 0.4 mm), floor 2.4 mm
- **Volume:** ~86.8 cm3, roughly 105 g of PLA

## Print settings (Snapmaker U1, 0.4 mm nozzle)

| Setting | Value |
|---|---|
| Orientation | As exported, flat base on the plate |
| Supports | None needed (no overhangs) |
| Layer height | 0.2 mm (0.16 mm for a smoother finish) |
| Walls | 4 perimeters (1.6 mm); floor 12 bottom layers |
| Infill | 10-15%, only affects the floor |
| Material | PLA / PLA Silk; multi-colour: one colour per cell works well on the U1's tool changer |
| Print time | Roughly 5-6 h at 0.2 mm (estimate; confirm in the slicer) |
