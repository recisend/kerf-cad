# Hive Desk Organizer (original design)

Seven-cell honeycomb desk organizer for pens, brushes, tools and makeup brushes. Fully original geometry, not based on any real product, brand or character.

## Print profile (Snapmaker U1, 0.4 mm nozzle)
- File: `hive-desk-organizer.3mf` (mm). Print as exported: open end up, flat base on the bed, **no supports**.
- Size: 117.6 x 113.4 x 90 mm (U1 volume is 270 mm cube).
- Walls 1.2 mm (3 perimeters at 0.4 mm), floor 2.0 mm (10 layers at 0.2 mm). Shared walls between cells are 1.2 mm.
- Suggested: 0.2 mm layers, 3 walls, 3 bottom layers, 15% infill (walls dominate), PLA/PETG. Volume 75.8 cm3 solid, so the real filament use is lower.
- Cell heights 90 / 75 / 60 mm for a staggered look. Single-color; try a color-change at layer ~ 150 (30 mm) for a gradient on the U1.
