# Facet Planter + Saucer (2026-11-13)

Original hexagonal tapered planter with matching drip saucer. No real-world brands/items/characters.

## Print settings (Snapmaker U1, 0.4 mm nozzle, PLA/PETG)
- Export: 3MF (`facet-planter-set.3mf`, 2 parts, mm, laid flat on build plate, no supports needed)
- Layer height 0.20 mm, line width 0.42-0.45 mm
- Walls: 2.4 mm = 6 x 0.4 mm lines -> use 6 perimeters (or 4 at 0.6 mm width)
- Floor/base: 2.4 mm (12 layers @ 0.2) ; drainage holes 8 mm centre + 6 x 5 mm
- Walls taper outward 8 deg -> no supports; saucer is 10 mm tall, no overhangs
- Infill 0-10%, no supports, brim not needed; vase-friendly
- Planter 79.7 x 92 x 85 mm (~66 g), saucer 72.7 x 84 x 10 mm (~19 g), both fit the 270^3 bed together
- Saucer inner fit: planter base 58.9 mm flat-to-flat in 67.9 mm saucer interior
