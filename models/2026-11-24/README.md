# Hex Honeycomb Desk Organizer (2026-11-24)

Original geometric design. It is not based on any real product, brand or character.
7 hexagonal cells of staggered height (60 / 75 / 95 mm) for pens, brushes, tools and small items.

## Files
- `hex-honeycomb-desk-organizer.3mf` – print file (single part, mm)
- `hex-honeycomb-desk-organizer.kerf.json` – editable Kerf CAD source
- `hex-organizer-render.png` – preview render

## Size
117 x 113 x 95 mm (Snapmaker U1 build volume is 270 x 270 x 270 mm, so it fits with room to spare)

## Printer-optimised for Snapmaker U1, 0.4 mm nozzle
- Wall thickness 1.6 mm (4 perimeters at 0.4 mm line width), floor 2 mm
- No overhangs and no supports needed; the flat base prints directly on the plate
- Single watertight part, no thin features under 1.6 mm

## Suggested slicer settings (Snapmaker Orca)
- Nozzle 0.4 mm, layer height 0.2 mm
- Walls 4, top layers 0 (open cells), bottom layers 5
- Infill 10% gyroid (the part is almost entirely walls)
- Supports off, brim optional
- Orientation: as exported (open end up)
