# Honeycomb Desk Tidy (2026-11-11)

Original design, not based on any real product, brand or character.

Four fused hexagonal cups (35 / 50 / 70 / 90 mm tall) for pens, brushes, clips and small tools.
Modeled in Kerf CAD; parametric via `#wall` and `#floor` variables in the `.kerf.json`.

## Why this one
Searches for current Etsy demand (Nov 2026) repeatedly name desk/home organization, plus gift-friendly
useful items, as steady categories during the holiday season. These sources are mostly vendor blogs, not
Etsy sales data, so treat the demand claim as directional, not proven.

## Snapmaker U1 print profile (0.4 mm nozzle)
- Build volume 270 x 270 x 270 mm. Part is 95.3 x 77 x 90 mm, one piece, no supports, flat base on the bed.
- Walls 1.6 mm (4 x 0.4 mm lines), floor 2.0 mm (10 layers at 0.2 mm). Shared walls between cups are 3.2 mm.
- Suggested: 0.2 mm layers, 3-4 wall loops, 3 top / 5 bottom layers, 10-15% infill (only the base is solid).
- Volume about 58 cm3, roughly 72 g of PLA (estimate at 1.24 g/cm3, before slicer settings).
- Multi-colour option: the U1 has 4 toolheads, so each cup can be a different colour by painting in the slicer.
- Geometry is checked only in Kerf's renderer. Slice it once in Snapmaker Orca and look at the preview before you list it.
