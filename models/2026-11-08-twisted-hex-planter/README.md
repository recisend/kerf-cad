## Print setup (Snapmaker U1, 0.4 mm nozzle, Snapmaker Orca)
The 3MF is geometry only. Kerf cannot embed a slicer profile, so select the U1 printer and 0.4 mm nozzle profile in Snapmaker Orca.

| Setting | Value |
|---|---|
| Orientation | As exported, flat bottom on the bed |
| Supports | None needed. Steepest overhang is about 35° from vertical. |
| Layer height | 0.20 mm (0.12 mm for a smoother twist, but slower) |
| Walls | 3 to 4 loops. Walls are about 2.8 mm, so 4 loops fill them. |
| Wall generator | Arachne (default) |
| Top/bottom layers | Bottom 5 or more (3 mm floor) |
| Infill | 10 to 15% gyroid. The planter is mostly walls. |
| Brim | Use a brim on the U1, as MakerWorld U1 model pages recommend. |
| Seam | Aligned or back, to hide it in a twist valley |
| Material | PLA or PETG. Use PETG for outdoor use. |

The drain hole is 7 mm, and the saucer catches the water. The twist is made of straight lofted segments (10 mm steps), which gives a faceted, crystalline look.
