# Faceted Wave Vase

Original, abstract geometric vase (not a copy of any real product, brand or character). Designed in Kerf CAD as a single revolved profile.

Files: `faceted-wave-vase.3mf` (print file), `faceted-wave-vase.kerf.json` (editable source).

## Geometry (verified)
- 76 x 76 x 100 mm, fits the Snapmaker U1's 270 x 270 x 270 mm volume with room for batch plates
- Wall 2.0 mm (5 perimeters at 0.4 mm), floor 2.4 mm (12 layers at 0.2 mm)
- Watertight mesh: 6048 triangles, 0 open edges, volume 45,365 mm3 (about 56 g PLA solid-equivalent, much less sliced)
- Flat base, no supports needed; steepest overhang is the lip flare, about 26 degrees from vertical

## Suggested Snapmaker U1 settings (0.4 mm nozzle)
- Layer height 0.20 mm (0.16 mm for a smoother finish)
- 5 walls, 0% infill is fine because the walls and floor are solid; use 2-3 bottom layers beyond the 2.4 mm floor if you want
- Supports off, brim off (wide flat base)
- Spiral/vase mode: not recommended. This design is built with real walls, so it is watertight when sliced normally
- Filament: PLA or PLA+ in one colour; silk PLA shows the ribbed profile best
- This is a decorative, dry-use vase. It is not food-safe, so put a glass or jar inside for fresh flowers or water
