# Hex Honeycomb Desk Organizer (2026-11-08)

Original design: seven hexagonal cells at staggered heights (40 to 100 mm), one solid part, no supports. It is not a copy of any real product, brand, character or existing design. Built in Kerf CAD through the MCP server (`hex-honeycomb-desk-organizer.kerf.json` is the editable source).

## Files
- `hex-honeycomb-desk-organizer.3mf`: print file (millimetres, one manifold part, 0 open edges, volume 66.4 cm3)
- `hex-honeycomb-desk-organizer.kerf.json`: editable Kerf source
- `preview.png`: render for listing mockups (re-render on a clean background or print one for the Etsy photos)

## Snapmaker U1 / 0.4 mm nozzle optimisation
| Item | Value | Why |
|---|---|---|
| Overall size | 88.3 x 85.0 x 100 mm | Fits the 270 x 270 x 270 mm bed; leaves room to print several at once |
| Wall between cells | 2.4 mm (2 x 1.2 mm) | Six perimeters at 0.4 mm |
| Outer wall | 1.2 mm | Three perimeters at 0.4 mm |
| Floor | 2.0 mm | Ten layers at 0.2 mm |
| All heights | Multiples of 0.2 mm | Match 0.2 mm layers with no rounding |
| Overhangs / supports | None | Vertical walls and a flat bottom; no supports, no bridges |
| Orientation | Flat on the bed, open side up | As exported |

Suggested slicer profile: 0.4 mm nozzle, 0.2 mm layer, 3 walls, 3 top/bottom layers, 10-15% infill (the part is almost all wall, so infill hardly matters), PLA or PETG. Estimated filament is about 82 g of PLA (66.4 cm3 x 1.24 g/cm3); get the real print time from the Snapmaker slicer. It is single colour as exported, but each cell is its own region if you want to colour them on the U1's four toolheads.
