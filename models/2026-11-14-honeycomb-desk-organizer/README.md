# Honeycomb Desk Organizer (original design, 2026-11-14)

Generic 7-cell hexagonal desk/craft organizer (pens, brushes, makeup brushes, tools).
Original geometry, no brands, characters or real-product likenesses.

**Trend basis:** desk/workspace organizers and functional storage are consistently named among top-selling
3D prints on Etsy in 2026 (vendor/seller guides - not verified Etsy sales data). Holiday gifting season
(Nov-Dec) boosts gift-type items. Planters sell weakly; licensed lightboxes are excluded (IP risk).

## Snapmaker U1 / 0.4 mm nozzle settings
- Footprint 135.1 x 130.0 x 80 mm (bed is 270 x 270 x 270) - fits easily; can print 2 at once.
- Print orientation as modelled: flat base on Z=0, **no supports, no overhangs**.
- Walls: outer 1.2 mm (3 perimeters), shared walls 2.4 mm (6 perimeters), floor 2.0 mm (10 layers @ 0.2).
- Layer height 0.2 mm (0.16 for nicer finish); line width 0.4-0.42; 2-3 perimeters min; 10-15% infill (walls dominate).
- Material: PLA / PLA+ (about 125 g est.). Multicolour: use the U1 toolchanger to alternate cell colours
  (cell heights alternate 80 / 66 / 52 mm so colour-per-cell is easy to assign in the slicer).
- Chosen 3MF export. Mesh from Kerf is slicer-ready (single watertight part).
