# Honeycomb Desk Organizer (2026-11-14)

Original geometric design, not based on any real-world product, brand or character.
Source: `honeycomb-desk-organizer.kerf.json` (parametric, built with Kerf MCP). Print file: `honeycomb-desk-organizer.3mf`.

## Geometry
- 7 hexagonal cells in a honeycomb flower; stepped heights 55 / 60 / 65 / 75 / 85 / 95 / 100 mm
- Footprint 114.3 x 110 mm, height 100 mm (Snapmaker U1 volume 270 x 270 x 270 mm: fits with large margin)
- Wall 1.2 mm per cell (= 3 perimeters at 0.4 mm line width; 2.4 mm shared between neighbours)
- Floor 1.6 mm (8 layers at 0.2 mm), flat bottom, no overhangs, no supports needed
- Part volume ~94.5 cm3, ~117 g PLA solid-model estimate (slicer infill will reduce this)
- Cell inner width ~35.7 mm flat-to-flat: fits pens, brushes, scissors, tools, makeup brushes

## Suggested slicer settings (Snapmaker U1, 0.4 mm nozzle)
- Layer height 0.2 mm, line width 0.42 mm, 3 walls, 6 top/bottom layers (floor is thin, so 8 bottom layers is ideal)
- Infill 10-15% gyroid (walls dominate), supports OFF, brim OFF (large flat base) or 3 mm brim if bed adhesion is marginal
- Enable elephant-foot compensation about 0.1-0.15 mm
- Orient as exported (flat base on bed). Vase/spiral mode is NOT suitable (shared walls)
- Multicolour option on the U1: print each cell height band in a different colour, or use a gradient/silk filament
