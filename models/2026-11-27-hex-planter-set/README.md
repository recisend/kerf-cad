# Hex Planter Set (2026-11-27)

Original geometric design (hexagonal succulent planter + matching drip saucer). Not based on any real product, brand or character.

**Why this product:** planters/vases, desk organizers and personalised gifts are repeatedly cited as steady Etsy 3D-print sellers; planters also fit Christmas gifting. (Sources are vendor blogs, so demand is directional, not verified sales data.)

## Print settings (Snapmaker U1, 0.4 mm nozzle)
- Parts: Planter 69 x 80 x 70 mm, Saucer 80 x 92 x 8 mm (U1 bed 270 x 270 x 270) - both fit on one plate
- Orientation: as exported, flat bottom on the bed, no supports needed (all walls vertical)
- Walls 1.2 mm (3 perimeters x 0.4), floor 2.0 mm, drain hole 8 mm
- Suggested: 0.2 mm layers, 3 walls, 3 bottom / 4 top layers, 10-15% infill (planter is nearly all wall), PLA/PETG
- Tip: vase/spiral mode is NOT suitable (drain hole in floor); print normally
- Planter sits inside saucer with ~4.6 mm clearance per side
