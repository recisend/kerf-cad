# Honeycomb Desk Organizer (2026-11-07)

Original geometric design (7 hex cells, staggered heights 60 / 75 / 90 mm). Not based on any real product, brand or character.

- Size: 99.6 x 96.1 x 90 mm (fits Snapmaker U1's 270 mm bed easily, can print several per plate)
- Files: `honeycomb-desk-organizer.3mf` (print), `.kerf.json` (editable in Kerf), preview PNGs

## Snapmaker U1 / 0.4 mm nozzle tuning
- Walls 1.2 mm = exactly 3 perimeters at 0.4 mm line width, shared walls between cells are 1.2 mm
- Floor 1.6 mm = 8 layers at 0.2 mm; all heights are multiples of 0.2 mm
- Flat base, vertical walls only: no supports, no brim needed
- Suggested: PLA, 0.2 mm layer, 3 walls, 3 top/bottom layers, 15% infill (walls dominate), ~75 g
- Optional: vase/spiralize is NOT suitable (shared walls); use normal mode
