## Snapmaker U1 / 0.4 mm nozzle fit
- Size 112.8 x 108.5 x 95 mm; U1 build volume is 270 x 270 x 270 mm, so it fits with lots of room (several copies per plate are possible only in X/Y, 2 fit side by side).
- Flat bottom, vertical walls, open top: **no supports, no brim needed**.
- Shared cell walls are 1.6 mm = exactly 4 x 0.4 mm perimeters. Floor 2.4 mm = 12 layers at 0.2 mm.
- Exterior walls are 0.8 mm (2 perimeters) – fine for desk use, but handle gently; consider 3 walls in the slicer if a sturdier feel is wanted.
- Suggested slicer start (Snapmaker Orca, PLA): 0.20 mm layer height, 4 walls, 3-4 top/bottom layers, infill irrelevant (almost no interior), 200+ mm/s outer wall per Snapmaker's reference profile. These are suggestions, not verified print results: print a test copy before listing.
- Estimated material ~86 g PLA (69.3 cm3 x 1.24 g/cm3).
