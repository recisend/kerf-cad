# Frost Star Ornament (2026-11-11)

Original six-arm geometric snowflake ornament with hanging loop. Not based on any real product, brand or licensed design.

**Why this one:** the research I could do points to holiday/seasonal items (Dec volume is claimed to be 3–5x normal) and gifts/decor as strong Etsy categories. Those figures come from vendor blogs, not Etsy data, so treat them as directional. I couldn't verify real sales numbers. Check Etsy's own search and best-seller pages before pricing.

## Model
- Size: 85.0 x 82.5 x 3.0 mm, single part, ~14.5 g in aluminum default density (a PLA print will weigh roughly 7 g).
- Prints flat, no supports, no overhangs.
- Minimum feature width 3.6 mm (9 perimeters at 0.4 mm). Hanging hole 4.4 mm.

## Snapmaker U1 / 0.4 mm nozzle suggestions
Starting points only. The 3MF holds geometry and units (mm); it does not carry slicer profiles.
- Nozzle 0.4 mm, line width 0.42 mm, layer height 0.2 mm (3 mm = 15 layers).
- 3 perimeters, 3 top and 3 bottom layers, infill 100% (the part is thin).
- Fits the U1 bed easily, so several ornaments can be printed per plate.
- Single color works; the U1 can also do a two-color version by splitting the part at a layer change (not done here).
