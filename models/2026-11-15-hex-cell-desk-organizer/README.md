# Hex-Cell Desk Organizer (original design, 2026-11-15)

Seven-cell stepped honeycomb organizer for pens, brushes, scissors, rulers. Original geometric design; it does not replicate any real-world product, brand or character.

- Size: 85.6 x 82.7 x 70 mm (fits the Snapmaker U1's 270 mm bed with room for several copies)
- Volume ~51.2 cm3; about 64 g in PLA (1.24 g/cm3) at 100% — real use will be less with sparse infill
- Walls 1.6 mm (4 lines at 0.4 mm), floor 2.0 mm (10 layers at 0.2 mm), flat base, vertical walls: no supports needed
- Cell heights 35-70 mm, inner flat-to-flat 26.4 mm

## Print profile (Snapmaker U1, 0.4 mm nozzle)
- Layer height 0.20 mm, line width ~0.42 mm, 4 walls, 3 top / 3 bottom layers, 10-15% gyroid infill
- PLA (or PETG), print upright, no supports, no raft; brim optional
- Multi-colour option: U1 has 4 toolheads, so a colour-change per height band or a 2-colour gradient suits this shape
