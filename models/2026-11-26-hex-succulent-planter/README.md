# Hex Succulent Planter + Drip Saucer (original design)

Original geometric design, not based on any real product, brand, character or licensed item.

## Files
- `hex-succulent-planter.3mf` – 2 parts (planter, saucer) laid out on one plate, mm
- `hex-succulent-planter.kerf.json` – editable Kerf CAD source
- `preview.png` – render

## Dimensions
- Planter: 69.3 x 80 x 70 mm (tapers 64 -> 80 mm across corners), ~2.1 mm walls, 1.2 mm floor, 7 mm drain hole
- Saucer: 65.8 x 76 x 10 mm, 8.8 mm deep pocket, 1.2 mm floor
- Plate footprint ~ 190 x 80 mm: fits Snapmaker U1 (270 x 270 x 270 mm) easily

## Snapmaker U1 / 0.4 mm nozzle recommendations (set in Snapmaker Orca / OrcaSlicer)
- Nozzle 0.4 mm, layer height 0.20 mm (0.16 mm for finer look), line width ~0.42 mm
- Walls: 5 x 0.42 mm = 2.1 mm wall -> use 4–5 wall loops, Arachne wall generator
- Top/bottom layers: 6 bottom (1.2 mm), 5 top; infill 10–15 % (walls carry the part)
- No supports: all walls lean < 7 deg from vertical, floor is flat. No brim needed.
- Print planter upright, saucer flat. Use "ironing" off, "seam: aligned/back" on a corner.
- Single colour recommended; for U1 multicolour, swap filament at a layer height of your choice
  (e.g. contrast colour for the saucer, or 2-colour rim at last 3 mm).
- Material: PETG recommended for wet use (planter holds soil/water); PLA OK for dry/décor use.
  Print time estimate: ~3–4 h planter + ~1 h saucer at standard speeds (verify in slicer).
