## Model
- 7 hex pockets (pens, brushes, makeup brushes, tools, cables), 91.3 x 105.4 x 80 mm
- Walls between pockets 2.0 mm (5 x 0.4 mm lines), outer wall ~2.1 mm, floor 2.0 mm
- Flat bottom with 0.8 mm chamfer (elephant-foot relief), no overhangs, no supports
- Fits Snapmaker U1 (270 x 270 x 270 mm) with lots of room; one piece, ~214 cm3 geometry

## Snapmaker U1 / 0.4 mm nozzle print settings (suggested)
- Nozzle 0.4 mm, layer height 0.20 mm (0.16 mm for finer look), line width 0.42 mm
- 4 walls (1.6 mm) minimum, 5 top/bottom layers, infill 10-15 % gyroid
- Supports: none. Orientation: as modelled (flat on bed)
- PLA / PETG; use the U1's multicolour toolheads for a gradient or 2-tone rim if desired
- Import the 3MF into Snapmaker Orca and pick the Snapmaker U1 profile
