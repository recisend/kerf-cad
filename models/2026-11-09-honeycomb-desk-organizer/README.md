## Model facts (measured from the exported 3MF)
- Size: 98.8 x 95.4 x 90.0 mm (U1 bed is 270 x 270 x 270 mm; fits with a wide margin)
- Volume: 70,367 mm3 (about 87 g of PLA at 100% solid)
- Watertight mesh: 0 open or non-manifold edges, 904 triangles
- Cell heights: 90 / 70 / 50 mm. All are multiples of 0.2 mm, so layers land cleanly.
- Floor: 1.6 mm (8 layers at 0.2 mm). Walls: about 1.62 mm outer and 1.64 mm shared, which is 4 perimeters at 0.4 mm.
- No overhangs and no bridges. Flat base, vertical walls. **No supports needed.**

## Snapmaker U1 slicing (0.4 mm nozzle)
Start from the stock Snapmaker U1 0.4 mm profile, then:
- Layer height: 0.20 mm
- Walls: 4 (1.6 mm). Top/bottom layers: 8 / 8 (the part is nearly all walls, so infill is almost irrelevant)
- Infill: 10-15% gyroid
- Supports: off. Brim: off (use a 3-5 mm brim only if the bed adhesion is marginal on your plate)
- Orientation: as exported (open end up, flat floor on the bed)
- Material: PLA, using the filament profile for your spool
- Seam: aligned or back, so the vertical seams are hidden in the wall corners
- The U1 is a 4-toolhead printer. The model is a single body, so it prints in one colour. To make it multicolour, split it per cell later.

I did not simulate the slicer, so print time and filament use are not measured. Slice once and check before quoting times in a listing.
