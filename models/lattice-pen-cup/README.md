# Lattice Pen Cup (2026-11-10)

Original design: a round desk cup with a diamond-lattice wall. It copies no real product, brand or character.
Built with the Kerf CAD MCP. Source: `lattice-pen-cup.kerf.json`. Print file: `lattice-pen-cup.3mf` (millimetres).

## Size
80 mm diameter x 100 mm tall. Fits the Snapmaker U1 (270 x 270 x 270 mm) with room for several cups on one plate. Mass is about 55 g of PLA.

## Optimised for Snapmaker U1, 0.4 mm nozzle
- Wall is 1.6 mm, which is 4 perimeters of 0.4 mm. No gap-fill needed.
- Floor is 3.2 mm, which is 16 layers at 0.2 mm. Height is a multiple of 0.2 mm.
- Flat bottom, prints without supports. Every diamond window has a 45 degree roof (self-supporting).
- Web between windows is at least 2 mm (5 perimeters of 0.4 mm wide).

Suggested slicer settings:
- Layer height: 0.2 mm.
- Walls: 4.
- Top and bottom layers: 4 and 16.
- Infill: not relevant (walls only).
- Supports: off.
- Seam: aligned or back.
- Material: PLA, or PETG for a tougher cup.

## Not done / to check
- A 0.6 mm first-layer chamfer was attempted. Kerf could not select the circular base edge, so it is left out. Enable "elephant foot compensation" in the slicer instead.
