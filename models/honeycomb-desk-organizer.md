# Honeycomb Desk Organizer

Original design (no real-world, branded or licensed item). Made in Kerf CAD, exported as 3MF.

## Print profile — Snapmaker U1, 0.4 mm nozzle
| Setting | Value | Why |
|---|---|---|
| Orientation | As exported (flat base on Z=0) | No supports, no bridges, no overhangs |
| Size | 95.5 x 92.2 x 90 mm | U1 bed is 270 x 270 x 270 mm; fits with room to spare |
| Layer height | 0.20 mm | Walls are straight, so there is no benefit to finer layers |
| Walls | 4 perimeters (1.6 mm) | Wall thickness is exactly 4 x 0.4 mm lines, so there is no gap-fill |
| Bottom / top layers | 10 bottom (2.0 mm floor), top n/a | Floor is 2.0 mm = 10 x 0.2 mm layers |
| Infill | 0-5% (almost everything is perimeters) | |
| Supports | Off | |
| Material | PLA / PETG | Est. 87 g in PLA |
| Colour | Single part. Use U1 multi-toolhead for a colour per cell if you split the part in the slicer | |

Geometry: 7 hexagonal cells, 32.9 mm flat-to-flat outside, 29.7 mm inside; heights 90 / 70 / 55 mm.
