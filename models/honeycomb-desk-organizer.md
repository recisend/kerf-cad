# Honeycomb Desk Organizer — original design (2026-11-26)

Original geometric design: 7 hexagonal cells in staggered heights (60–90 mm).
Not based on any real product, brand, character or licensed item.

- `honeycomb-desk-organizer.3mf` — print file (mm, single watertight part, solid volume 134.3 cm³)
- `honeycomb-desk-organizer.kerf.json` — editable Kerf source
- `honeycomb-organizer-iso.png` — preview render

## Optimised for Snapmaker U1, 0.4 mm nozzle
- Footprint 124.7 x 120 mm, height 90 mm — fits the bed with large margin
- Outer walls 1.6 mm = exactly 4 x 0.4 mm lines; shared walls 3.2 mm = 8 lines (no gap-fill artifacts)
- Floor 2.0 mm = 10 layers at 0.2 mm; all heights are multiples of 0.2 mm
- Vertical walls, flat bottom, no overhangs: **no supports, no brim needed**
- Suggested slicer settings: 0.4 mm nozzle, 0.2 mm layer, 4 walls, 3 top/bottom layers, 10–15% infill, PLA/PETG
- Note: mesh is geometrically closed (signed volume matches CAD) but has T-junction edges where cells of different heights meet; slicers normally accept this. If yours warns, run its auto-repair.

## Trend rationale (directional, not guaranteed)
Web research (vendor blogs, not hard Etsy sales data) repeatedly lists desk organizers / personalised desk accessories as steady sellers. Brand-logo and character items were the other top sellers but carry licensing risk, so this design deliberately avoids them. Honeycomb/hex is a recognisable, giftable look and prints reliably.
