# Honeycomb Desk Organizer (2026-11-11)

Original geometric design (no real-world product, brand or character). Seven fused hexagonal cells at three heights (95 / 75 / 55 mm) for pens, brushes, scissors and tools.

- Size: 120 x 115.5 x 95 mm, about 148 g PLA (solid-wall estimate before slicer infill)
- Fits the Snapmaker U1 build volume (270 mm cube) with plenty of margin
- File: `honeycomb-desk-organizer.3mf` (editable source: `.kerf.json`)

## Snapmaker U1 / 0.4 mm nozzle settings

| Setting | Value | Why |

| Nozzle | 0.4 mm | Wall thickness 1.6 mm = exactly 4 x 0.4 mm lines, 3.2 mm shared walls = 8 lines |
| Layer height | 0.2 mm | Floor is 2.0 mm = 10 layers |
| Walls | 4 loops | Matches 1.6 mm wall, no gap fill |
| Top/bottom layers | 5 / 5 (floor is solid) | |
| Infill | 10-15 % gyroid (walls are nearly solid) | |
| Supports | None | Flat base, vertical walls, no overhangs |
| Orientation | As exported (flat base down) | |
| Brim | Optional 3 mm if bed adhesion is marginal (tall, narrow-ish part) | |
| Material | PLA or PETG | |
