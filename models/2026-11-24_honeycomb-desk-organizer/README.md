# Honeycomb Desk Organizer (2026-11-24)

Original geometric design. No brand, character or real-product reference.

**Files**
- `honeycomb-desk-organizer.3mf` – print file (mm, one part, watertight: 0 unmatched mesh edges)
- `honeycomb-desk-organizer.kerf.json` – editable Kerf CAD source
- `preview-iso.png`, `preview-top.png` – renders

**Geometry:** three hexagonal cups (100 / 80 / 60 mm tall) tiled edge to edge, 103.9 × 105 × 100 mm.
Cup interior is 48.8 mm flat to flat. Volume 76.9 cm³ (about 95 g if solid PLA; real use is lower).

## Snapmaker U1 / 0.4 mm nozzle design choices
| Feature | Value | Why |
|---|---|---|
| Outer wall | 1.6 mm | 4 perimeter lines at 0.4 mm |
| Shared wall between cups | 3.2 mm | 8 lines, no gap-fill needed |
| Floor | 1.6 mm | 8 layers at 0.2 mm |
| Base edge chamfer | 0.4 mm | counters elephant-foot |
| Overhangs / bridges | none | prints upright with **no supports** |
| Footprint | fits 270 mm bed | single-colour, any filament |

## Suggested slicer settings (not slice-tested here)
0.4 mm nozzle, 0.2 mm layer height, 4 walls, 8 bottom layers, 5 top layers, 10–15% infill
(the walls are almost all perimeters), no supports, no brim. PLA at the U1 default PLA profile.
Optional: print each cup colour via the U1's four toolheads, for example a colour change per cup.
