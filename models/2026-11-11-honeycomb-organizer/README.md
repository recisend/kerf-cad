# Honeycomb Desk Organizer (2026-11-11)

Original geometric design (no real-world product, brand or character). Seven hexagonal cells of staggered height, usable as a pen / brush / tool holder.

## Files
- `honeycomb-desk-organizer.3mf` – print file (mm units)
- `honeycomb-desk-organizer.kerf.json` – editable Kerf CAD source
- `preview.png` – render

## Dimensions
- Footprint 106.8 x 102.8 mm, height 110 mm (Snapmaker U1 bed: 270 x 270 x 270 mm – fits with wide margin)
- Cell inner width 34 mm across flats; cell heights 55-110 mm
- Wall 1.6 mm (4 perimeters at 0.4 mm), floor 2.0 mm (10 layers at 0.2 mm)

## Snapmaker U1 / 0.4 mm nozzle settings (suggested)
- Orientation: as modelled, flat bottom on the plate. No supports needed (all walls vertical, no overhangs).
- Layer height 0.2 mm, line width 0.42-0.45 mm, 4 walls, 3-4 bottom layers, 0% infill is fine (walls only); 15% gyroid if you want extra stiffness.
- PLA: ~220 C nozzle, ~60 C bed. Estimated filament ~85 g at 100% solid; far less with sparse infill.
- Print speed: outer walls 60-100 mm/s keeps the tall thin walls from wobbling; enable a brim if bed adhesion is marginal on tall corner cells.
- Multi-colour idea for the U1's toolheads: a different filament per cell height/layer range or a colour change at the floor.
