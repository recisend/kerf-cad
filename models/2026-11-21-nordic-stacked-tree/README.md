# Nordic Stacked Tree (2026-11-21)

Original, abstract tiered holiday tree with a gold gem topper. Not based on any real product, character or brand.

**Why this model:** the run date is late November, the start of Etsy's holiday buying peak. Research showed seasonal table décor and desk pieces among commonly listed 3D-print sellers. Sources are vendor blogs, not Etsy sales data, so treat the trend as directional only.

## Printer: Snapmaker U1, 0.4 mm nozzle
- Build volume is 270 x 270 x 270 mm. The model is 92 x 92 x 136 mm, so it fits with room to spare.
- No supports needed. The maximum overhang is 45 degrees, in the step under each tier.
- The flat base is 92 mm wide, so it sticks to the bed well, and there is a 3 mm vertical lip at the first layer.
- Smallest feature is the 1.2 mm-radius topper tip. Everything else is much thicker than 0.8 mm (two perimeters).
- Two parts, Tree (green, #1f6b4a) and Gem Topper (gold, #d4af37), so the U1's multi-tool setup can print two colours. Assign one filament to each part in the slicer.

## Suggested slicer settings (starting point, not tested on a U1)
- Layer height 0.2 mm, 3 perimeters, 10-15% gyroid infill, 4 top and bottom layers, supports off.
- Solid volume is about 293 cm3. With 15% infill expect well under 100 g of filament. Check the real figure in the slicer.
