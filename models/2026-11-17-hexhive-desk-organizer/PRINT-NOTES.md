# HexHive Desk Organizer (original design, 2026-11-17)

Three-cell honeycomb pen/desk organizer, heights 70 / 90 / 110 mm. Original geometric design, not based on any real-world product, brand or character.

**Why this niche:** web research this run (vendor blogs, SEO tools - directional, not hard sales data) lists desk/drawer organizers and honeycomb/modular desk gear among consistently selling 3D prints, with personalised desk decor rising. Verify against Etsy search data before listing. Etsy requires original designs - this is one.

## Snapmaker U1 / 0.4 mm nozzle optimisation
- Footprint 88.9 x 90.0 mm, max height 110 mm (U1 volume 270^3).
- Walls 1.2 mm (3 x 0.4 mm perimeters), floor 1.6 mm (8 x 0.2 mm layers).
- Flat base, vertical walls: zero overhangs, no supports, no brim needed.
- Prints in one piece, upright. Suggested: 0.2 mm layer, 3 walls, 15% infill (walls dominate), top layers irrelevant (open top), Arachne walls.
- Solid volume about 49.6 cm3, roughly 60 g PLA.
- Single-colour as modelled; on the U1, colour per cell can be added in Snapmaker Orca.
- Not verified: exact U1 slicer profile (no official 3MF docs found); I did not slice it.
