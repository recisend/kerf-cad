# Honeycomb Desk Organizer: 2026-11-08

Original geometric design. It is not based on any real product, brand or character, and no existing file was copied.

## Files
- `honeycomb-desk-organizer.3mf`: print file (mm, single watertight part, flat on Z=0)
- `honeycomb-desk-organizer.kerf.json`: parametric source (open in Kerf; variables `#wall`, `#floor`)
- `preview.png`: render for listing photos (replace with real photos of the print once printed)

## Geometry
- Three interlocking hex cells: 95 / 70 / 50 mm tall
- Footprint 95.4 × 96.7 mm, height 95 mm (the Snapmaker U1 bed is 270 × 270 × 270 mm, so it fits with a wide margin)
- Walls 1.6 mm (4 perimeters at 0.4 mm), shared walls 1.6 mm, floor 2.4 mm (12 layers at 0.2 mm)
- Volume about 61.3 cm³, roughly 76 g of PLA at 1.24 g/cm³

## Snapmaker U1 / 0.4 mm nozzle settings (suggested)
| Setting | Value |
|---|---|
| Orientation | As exported, flat on the bed |
| Supports | None needed (all walls vertical, nothing overhangs) |
| Layer height | 0.20 mm (0.12 mm for a finer surface) |
| Line width | 0.42 mm |
| Walls | 4 (1.6 mm) |
| Top/bottom layers | 12 bottom (the floor is 12 layers, so it prints solid) |
| Infill | 10–15% (only the floor and wall joints use it) |
| Brim | Optional, 3–5 mm, since the footprint is large and tall |
| Seam | Aligned or back, to hide it on a corner |
| Material | PLA or PETG. Silk or two-tone PLA looks good on the faceted cells. |

I have not sliced or test-printed this. The settings above are standard 0.4 mm guidance, so check the slice preview and print one test unit before listing. The U1 is a multi-toolhead machine, so you can assign a different colour to each cell.
