# Honeycomb Desk Organizer (2026-11-08)

Original design, not based on any real product, brand or character. Four joined hexagonal cells of different heights (55 / 70 / 80 / 95 mm) for pens, brushes, makeup tools or small plants.

## Files
- `honeycomb-desk-organizer.3mf` - print file (mm, single part)
- `honeycomb-desk-organizer.kerf.json` - editable Kerf source
- `preview-iso.png`, `preview-top.png`

## Size and material use
- 101.5 x 82.6 x 95 mm. This fits the Snapmaker U1's 270 x 270 x 270 mm build volume with room to spare, so you could also print several in one batch.
- About 64.3 cm3, roughly 80 g of PLA (Kerf's estimate at solid density; actual use depends on your infill).

## Optimized for Snapmaker U1, 0.4 mm nozzle
- Walls are 1.6 mm, which is 4 perimeters at 0.4 mm line width. The shared walls between cells measure about 1.57 mm and slice cleanly as 4 lines.
- Floor is 2.0 mm, which is 10 layers at 0.2 mm.
- Flat bottom, vertical walls, no overhangs, so no supports, brim or raft are needed.
- Suggested slicer settings: 0.2 mm layer height, 4 walls, 5 bottom and 5 top layers, 10-15% infill. Infill barely matters because the walls are almost solid. Use a 0.4 mm nozzle profile for the U1 and PLA.
- Multicolor option: the U1 has 4 toolheads, so you can assign a different colour to each cell in the slicer. Do this with colour changes by height or by painting, since the part is a single object.
