# Fluted Desk Caddy (2026-11-19)

Original design, not based on any real-world product or brand.

**Why:** Research this run points to desk organizers and fluted/ribbed minimalist
pen holders as a steady Etsy category. The sources are seller guides and keyword
trackers, not official Etsy sales data, so treat the trend as directional.
Competition is heavy (~54k listings for "3d printed organizer"), and one keyword
tracker shows demand peaking in Nov 2025, so differentiate on finish, colour and
bundles.

**Geometry:** 80 mm dia x 95 mm tall, 24 vertical flutes (R3.5), 68 mm bore,
min wall about 2.5 mm, 2.4 mm floor (6 layers at 0.4 mm). The only unsupported
span is the open top, so no supports are needed.

**Snapmaker U1 / 0.4 mm nozzle suggested profile** (the file is geometry only, so
set these in the slicer):
- 0.2 mm layers, 0.42 mm line width, 3 walls, 4+ top/bottom layers, 15% gyroid infill (walls dominate)
- Spiral/vase mode is NOT suitable (the floor is solid). Use a normal profile.
- PLA, ~215 C nozzle, 60 C bed. Seam: aligned/back (hides in a flute).
- Print time about 4-5 h. Print upright on the plate and verify in the slicer.

**Ideas:** two-colour on the U1 (flute colour per layer range), matched set in 3 heights.
Export: `fluted-desk-caddy.3mf` (mm). Not published anywhere.
