# Honeycomb Desk Organizer (original design)

Generic 7-cell hexagonal pen / tool / brush organizer. Original geometry, not based on any real-world or branded product.

## Print settings (Snapmaker U1, 0.4 mm nozzle)
- File: `honeycomb-desk-organizer.3mf` (mm). Footprint 111.1 x 107.2 x 80 mm (U1 volume is 270 mm cube).
- Orientation: as exported, flat bottom on bed. No supports needed (all walls vertical).
- Walls/floor: 1.6 mm = exactly 4 perimeters at 0.4 mm line width; floor 1.6 mm = 8 layers at 0.2 mm.
- Layer height 0.2 mm, 0.4 mm nozzle, 2-3 bottom/top layers, 10-15% infill (walls are almost all perimeter).
- Approx. volume 72.5 cm3 (about 90 g PLA).
