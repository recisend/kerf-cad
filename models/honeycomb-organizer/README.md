# Honeycomb Desk Organizer (original design)

Seven-cell tiered hexagon desk organizer. Entirely original geometry, no real-world product, brand, character or licensed item.

**Files**
- `honeycomb-desk-organizer.3mf`: print file, millimetres, 8 coloured objects
- `honeycomb-desk-organizer.kerf.json`: editable Kerf CAD source
- `preview-iso.png`, `preview-top.png`: renders for the listing

## Snapmaker U1 print setup (0.4 mm nozzle)

| Item | Value |
|---|---|
| Size | 93.1 x 89.6 x 88 mm (U1 volume 270 x 270 x 270 mm) |
| Orientation | As exported, flat base on the plate, no supports, no brim needed |
| Nozzle / layer | 0.4 mm, 0.20 mm layers |
| Walls | 1.77 mm shared wall between cells (about 4 perimeters), outer rim 0.89 mm per cell |
| Infill | 15% (the walls are almost all perimeter anyway) |
| Colours / toolheads | 4: T1 `#2B2F36` charcoal (body), T2 `#D9A441` gold (centre rim), T3 `#E0705A` coral (3 mid rims), T4 `#F1E6D0` cream (3 low rims) |
| Material | PLA |
| Colour changes | Rims are at 88 / 72 / 58 mm; each tier changes colour once per layer range, so purge waste is small |

Slice in Snapmaker Orca: import the 3MF, assign each coloured object to a toolhead, check that filament profiles match the loaded spools.
