# Hexa Stack Desk Organizer (2026-11-12)

Original geometric design (no real-world product, brand or character). Four interlocking
honeycomb cells in a 30 / 45 / 60 / 75 mm height staircase for pens, brushes, scissors, clips.

- Size: 105 x 84.9 x 75 mm (fits the 270 mm Snapmaker U1 bed), ~35 cm3 solid, ~95 g Kerf default density (real PLA ~44 g)
- Files: `hexa-stack-desk-organizer.3mf` (export), `.kerf.json` (editable source), `preview.png`

## Snapmaker U1 / 0.4 mm nozzle optimisation
- Walls 1.6 mm (4 x 0.4 mm lines), floor 2.0 mm, all features >= 1.6 mm
- Flat base, vertical walls, 0.6 mm base chamfer (elephant-foot relief): **no supports needed**
- Suggested Snapmaker Orca settings: 0.4 nozzle, 0.2 mm layer, 4 walls (Arachne), 2 bottom / 3 top layers, 10-15 % infill, ~0.8 mm brim
- Nozzle in slicer must match the touchscreen nozzle (0.4) or the print will not start
- Multi-colour idea: paint each cell a different filament (U1 has 4 toolheads) - sells well as a colour set
