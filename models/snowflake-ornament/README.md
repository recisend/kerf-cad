## Snapmaker U1 / 0.4 mm nozzle optimisation

- Lies flat on the bed: no supports, no brim needed, no overhangs.
- Thinnest feature is ~2.6 mm (branches) = 6+ perimeter lines of 0.4 mm; the hanging hole is 4.6 mm, with a 2.3 mm wall around it.
- 3.0 mm thickness = exactly 15 layers at 0.2 mm, so no partial top layer.
- Suggested profile (Snapmaker's wiki recommends 0.1-0.3 mm layers, 0.2 mm typical, for the 0.4 mm U1 hot end):
  - Nozzle 0.4 mm, layer height 0.2 mm, 3 walls, 100% infill (the part is nearly all perimeters), 4 top / 4 bottom layers.
  - Multicolour option: the U1 is a 4-toolhead printer, so a colour change at layer 8-15 (or a two-colour version) is easy to add in the slicer.
- Open the 3MF in Snapmaker Orca, confirm the printer's nozzle is set to 0.4 mm, slice and print.
