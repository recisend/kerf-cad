## Specs
- Size: 101.8 x 103.2 x 90 mm (3 hex cells: 90 / 70 / 50 mm tall) - fits Snapmaker U1 bed (270^3) with room to spare

- No supports, no brim; print in PLA (or PETG); vase-like geometry prints fast
- Suggested colour: silk/matte PLA; optional multicolour via U1 toolheads (per-cell colour)
