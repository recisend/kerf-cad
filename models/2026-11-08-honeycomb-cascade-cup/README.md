# Honeycomb Cascade Desk Cup — 2026-11-08

Original, brand-free design (no real products, logos, characters or licensed shapes).
Seven fused hexagonal cells at stepped heights (55 / 65 / 70 / 80 / 85 / 90 / 100 mm) —
pens, brushes, makeup brushes, cutlery, dried flowers.

**Files**
- `honeycomb-cascade-desk-cup.3mf` — print file (mm, single part, manifold, welded)
- `honeycomb-cascade-desk-cup.kerf.json` — editable Kerf CAD source (open in the Kerf web app)

## Optimised for: Snapmaker U1 · 0.4 mm nozzle

| | |
|---|---|
| Overall size | 104.7 × 100.9 × 100 mm (U1 volume is 270 mm cube — fits with room to spare) |
| Volume | 101.2 cm³ → ~125 g PLA (1.24 g/cm³), before any slicer extras |
| Orientation | As modelled: flat base on the bed, open tops up. **No supports, no overhangs, no bridges.** |
| Outer wall | 1.6 mm (= 4 × 0.4 mm lines) |
| Wall between cells | 2.4 mm (= 6 × 0.4 mm lines) |
| Floor | 2.0 mm (= 10 layers at 0.2 mm) |
| Layer height | 0.20 mm recommended (any 0.08–0.28 mm works with a 0.4 mm nozzle; all Z features are multiples of 0.2 mm) |
| Walls / bottom layers | 4 walls · 10 bottom layers · infill irrelevant (walls ≈ 100 % of the part) |
| Supports | Off |
| Material | PLA / PETG; silk or marble PLA looks good on the flat faces |

Notes
- Snapmaker's U1 is a multi-toolhead machine: a colour change at the floor/cell-height
  layers is a cheap way to add a two-tone look, but this file itself is single-colour.
- Confirm in your slicer (Snapmaker Orca) that the U1 profile and 0.4 mm nozzle are selected —
  I could not run the slicer from this environment, so print time/filament are not measured.
- Mesh check: 445 vertices, 886 triangles, 0 open/non-manifold edges, consistent winding,
  mesh volume 101,152 mm³ = CAD volume.
