# Honeycomb Desk Organizer (original design, no real-world/branded items)

File: `honeycomb-desk-organizer.3mf` (mm, 1 part, 85 x 86 x 95 mm, ~51 cm3 / ~64 g PLA solid-equivalent)

## Snapmaker U1 / 0.4 mm nozzle settings (Snapmaker Orca, U1 profile)
- Build volume 270x270x270: fits with huge margin; print flat-base-down, **no supports**.
- Nozzle 0.4 mm, layer 0.20 mm (0.16 for nicer faces), 3 walls (1.6 mm walls = 4 x 0.4 lines; design wall = 1.6 mm)
- Floor 2.0 mm = 10 layers @0.2. Infill irrelevant (walls are fully perimeters); 2 top/bottom layers fine for the floor.
- PLA: nozzle 190-230 C, textured PEI bed 55-65 C (per Snapmaker wiki).
- Tip: use a different U1 toolhead filament per cell via color painting for a multi-color version.
