## Snapmaker U1 / 0.4 mm nozzle settings
Kerf's 3MF holds geometry only. It has no slicer profile, so apply these in the slicer.

| Setting | Value | Why |
|---|---|---|
| Printer / nozzle | Snapmaker U1, 0.4 mm | |
| Orientation | As exported: wide base flat on the bed | No supports needed |
| Supports | Off | Every overhang is 45° or less, and the cable notch is a vertical cut |
| Layer height | 0.20 mm (0.16 mm for a nicer finish on the sloped face) | |
| Walls | 3 loops (1.2 mm) | Multiple of the 0.4 mm line width |
| Top / bottom layers | 5 / 4 | |
| Infill | 15% gyroid | The stand is solid, about 328 g at 100% PLA, so infill matters for cost |
| Material | PLA / PLA+ | |
| Footprint | 80 x 120 mm, 90 mm tall | Fits the U1 build volume with a large margin |

Smallest wall in the model is about 5.6 mm, so there are no thin features for the 0.4 mm nozzle to struggle with.

Solid mass is about 328 g. At 15% infill, expect roughly 110–140 g of filament (an estimate; check the slicer's figure). That's a lot of plastic for a phone stand, so the Etsy price must cover it.

## Design features
- 73° backrest, with a 14 mm lip forming a groove for phone or small tablet
- 20 mm cable notch in the lip for a charging cable
- Two 45° diamond cutouts in the side to save weight and add a geometric look
- 80 mm wide for stability
