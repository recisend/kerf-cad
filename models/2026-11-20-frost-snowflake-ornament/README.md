## Snapmaker U1 / 0.4 mm nozzle settings
- Build volume 270 x 270 x 270 mm; part is 69 x 86 x 3.8 mm, so roughly 12 fit per plate
- Nozzle 0.4 mm, layer height 0.20 mm, line width 0.42-0.45 mm, 3 walls (about 1.3 mm), 4 top and bottom layers
- Infill 100% (the part is only 3 mm thick), no supports, no brim; print flat with the body on the plate
- Body = filament 1 (white or ice-blue PLA); medallion = filament 2 (gold PLA), starts at Z = 3.0 mm (a single colour change)
- Smallest features: arms 4.0 mm wide, branches 3.0 mm, gaps 2.9 mm or more, hang hole 3.2 mm with a 3 mm wall, medallion ring 3.5 mm wide; all well above the 0.4 mm nozzle limit
- PLA about 200-215 C nozzle, 55-60 C bed
