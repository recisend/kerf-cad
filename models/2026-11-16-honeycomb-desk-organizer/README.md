# Honeycomb Desk Organizer (2026-11-16)

Original generic design: seven connected hexagonal cups of stepped height (64 / 48 / 36 mm) for pens, brushes, tools, makeup brushes or small plants. No real-world product, brand, character or logo.

## Snapmaker U1 / 0.4 mm nozzle design rules applied
- Footprint 121.6 x 117.3 mm, height 64 mm (U1 build volume is 270 mm cube) – leaves room to plate several, or print 2 at once.
- All walls 1.6 mm = exactly 4 perimeters of a 0.4 mm line; floors 1.6 mm = 8 layers at 0.2 mm.
- Every cup is a vertical prism with a flat bottom: no overhangs, no supports, no bridges, no brim needed.
- Heights (64, 48, 36) and floor are multiples of 0.2 mm layer height (and 0.16 / 0.08 compatible).
- Single watertight solid, ~66.6 cm3, about 83 g of PLA solid-equivalent (real use ~60-70 g with 4 perimeters, 10-15 % infill).

## Suggested slicer profile (Snapmaker Orca / U1 0.4 nozzle)
- 0.20 mm layer (0.16 for a finer look), 4 walls, 4 top / 4 bottom layers, 10-15 % gyroid infill
- No supports, no brim; seam: aligned or back; ironing off
- PLA 210 C nozzle / 60 C bed (adjust for your filament)
- Optional: use the U1's multi-tool to print each cup height in a different colour via colour-change by layer or by object split.
- Estimated print time ~5-7 h (estimate; confirm in the slicer).
