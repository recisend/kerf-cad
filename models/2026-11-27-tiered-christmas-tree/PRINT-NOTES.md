## Model
- File: `tiered-christmas-tree.3mf` (2 objects: green Tree Body, gold Star Topper; part colours embedded). Source: `tiered-christmas-tree.kerf.json`.
- Size: 110 x 110 x 125 mm assembled (star glued/press-fit onto the flat top, 6x4 mm tab). Fits the Snapmaker U1 270 x 270 x 270 mm volume with room for several copies.
- Supports: none needed. Every tier underside is a 45 degree slope; flat base on the bed.

## Suggested slicer settings (Snapmaker U1, 0.4 mm nozzle; set in Snapmaker Orca, not embedded in the file)
- Layer height 0.20 mm, line width 0.42 mm, 3 walls, 3 top / 3 bottom layers, 12-15% gyroid infill, no supports, brim not needed.
- Tree: PLA green (extruder 1). Star: PLA gold/silk (extruder 2). Lay the star flat on the bed in the slicer (rotate 90 degrees about X) for a cleaner print.
- Tree is about 313 cm3 solid; with the settings above expect a long print, so batch on a full plate overnight.
