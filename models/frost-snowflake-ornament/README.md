# Frost Snowflake Ornament (original design)

Original geometric 6-arm snowflake ornament. Not based on any real product, character, brand or logo.

**Why this product (research, Nov 2026):** the "3d printed ornament" search peaks Nov–Dec; Etsy's 2026 holiday trend notes point to blue & silver palettes and "Enchanted Winter". Flat ornaments print fast and have low shipping cost. Competition is high (~20k listings), so differentiate with the two-colour blue/silver look and a bundle/set. Trend data is from seller blogs and keyword tools, so treat it as directional.

## Snapmaker U1 print settings (0.4 mm nozzle)
- Size: ~91.5 x 73.3 x 4.2 mm, ~5.5 g, print flat, no supports
- Layer 0.20 mm, line width 0.42 mm, 3 walls, 4 top / 4 bottom layers, 15% infill (or 100%: it is thin)
- Minimum feature width is 2.4 mm (about 6 lines), loop wall 2.5 mm, so nothing is below the nozzle's reliable range
- Assign part 1 (blue) to one toolhead and part 2 (silver) to another. The accent is 1.2 mm tall = 6 layers at 0.2 mm
- PLA, smooth PEI plate. Brim not needed
