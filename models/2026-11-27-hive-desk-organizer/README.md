# Hive Desk Organizer (2026-11-27)

Original design: four interlocking hexagonal cups of different heights (45 / 60 / 80 / 100 mm).
Not based on any real product, brand, character or licensed item.

- Footprint: 108.3 x 87.5 mm, height 100 mm (fits Snapmaker U1 270 x 270 x 270 mm)
- Files: `hive-desk-organizer.3mf` (print file, mm), `hive-desk-organizer.kerf.json` (editable Kerf source)

## Snapmaker U1 / 0.4 mm nozzle settings
- Orientation: as exported, flat on the bed. No supports needed (all walls vertical).
- Layer height 0.20 mm, line width 0.4-0.42 mm
- Outer wall 1.2 mm = 3 perimeters, shared walls 2.4 mm = 6 perimeters, floor 2.0 mm = 10 layers
- Walls are solid at 3 perimeters, so infill is irrelevant; use 2 bottom / 4 top layers
- PLA ~ 215 C nozzle; slight brim optional for the 100 mm tall cup
- Colour idea (U1 has 4 toolheads): change filament at layer heights 45 / 60 / 80 mm for a gradient look
