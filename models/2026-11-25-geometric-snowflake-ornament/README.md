# Geometric Snowflake Ornament (2026-11-25)

Original design, not based on any real product, brand or character.
Format: 3MF, 2 parts (white body + blue hex inlay) for the Snapmaker U1 multi-toolhead setup.

## Files
- `geometric-snowflake-ornament.3mf` - print file (mm)
- `geometric-snowflake-ornament.kerf.json` - editable Kerf source
- `preview-top.png`, `preview-iso.png`

## Model facts
- Size: 99 x 83 mm, 3 mm thick; fits the U1 bed (270 x 270 mm) with room for ~6 per plate
- Prints flat, no supports; hanging loop OD 8 mm / hole 3.6 mm
- Smallest feature width: 2.3 mm (>= 5 lines at 0.4 mm), min wall around hole 2.2 mm
- Weight: about 6.3 g body + 0.2 g inlay (PLA)
- Hub inlay is a flush 1 mm pocket (z 2-3 mm), so no overlap between parts

## Suggested slicer settings (Snapmaker U1, 0.4 mm nozzle)
- Layer height 0.2 mm, first layer 0.2 mm
- 3 walls (1.2 mm), 4 top / 3 bottom layers, infill 15% (nearly solid at this thickness anyway)
- No supports, no brim; 2 filaments: body white/silver, inlay blue/gold
- Print the loop-side arm toward the front of the plate; thread twine or ribbon through the loop
