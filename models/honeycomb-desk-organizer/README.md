# Honeycomb Desk Organizer (original design, 2026-11-23)

Seven fused hexagonal cells of staggered height (50–90 mm) for pens, brushes, makeup tools or cables.
Original geometric design, not based on any real product, brand or character.

## Model facts
- Size 95.6 x 92.1 x 90 mm (fits the Snapmaker U1's 270 mm build volume with room to spare)
- Volume 60.3 cm3, about 75 g PLA
- Single watertight solid, 0 non-manifold edges, units mm
- Wall 1.6 mm shared (4 x 0.4 mm perimeters), outer wall 1.2 mm (3 perimeters), floor 1.6 mm
- Flat base, vertical walls, no overhangs, no supports needed

## Snapmaker U1 / 0.4 mm nozzle print settings
- Nozzle 0.4 mm, layer height 0.20 mm (0.16 mm for a finer finish), first layer 0.2 mm
- 4 wall loops, 5 bottom and 4 top layers, infill 10-15 % (gyroid), supports off
- Print as-is, flat on the bed, no rotation. Brim not needed
- PLA 215 C / bed 60 C (adjust for your filament)
- Multicolour option for the U1's 4 toolheads: split per cell and assign a colour each, or colour-change by cell.
