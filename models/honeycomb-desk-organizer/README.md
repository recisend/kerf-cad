## Dimensions

- Footprint 90.4 x 87.3 mm, height 80 mm (3 short cells at 56 mm, 4 tall cells at 80 mm)
- Pockets 28 mm flat-to-flat (about 32 mm across corners), 78.4 mm / 54.4 mm deep
- Volume 66.4 cm3, about 82 g of PLA if printed solid-walled

## Optimised for Snapmaker U1 + 0.4 mm nozzle

| Rule | How the model meets it |
|---|---|
| Fits build volume (270 x 270 x 270) | 90.4 x 87.3 x 80 mm; room to print several at once |
| Walls are multiples of the 0.4 mm line width | 1.6 mm shared walls = exactly 4 perimeters, no gap-fill needed |
| Heights are multiples of the 0.2 mm layer | Floor 1.6 mm (8 layers), cell heights 56 and 80 mm |
| No supports | Pure vertical extrusion, flat bottom, zero overhangs or bridges |
| Clean mesh | Verified: 0 open/unpaired edges, no degenerate triangles |
| Format | 3MF, millimetres |

Suggested slicer settings (Snapmaker Orca): 0.4 mm nozzle, 0.2 mm layer height, 4 wall loops, 0 % infill is fine (walls fill the part), 5 top / 5 bottom layers, no supports, brim not needed, print flat on the plate. Use your preferred PLA or PETG profile for the U1. The U1 is a multi-tool printer, so per-cell colours can be assigned in the slicer if you want a two-tone version.
