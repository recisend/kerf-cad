# Honeycomb Desk Organizer (2026-11-14)

Original design: 7 interlocking hexagonal cells (pen / brush / tool holder) in 3 heights (90 / 70 / 50 mm).
Not based on any real product, brand or character.

- Footprint 99.6 x 96.1 mm, height 90 mm (Snapmaker U1 bed is 270 x 270 x 270 mm)
- Wall 1.2 mm (3 perimeters at 0.4 mm line width), floor 2.4 mm, flat base, no supports needed
- Volume ~60.4 cm3 (about 75 g PLA)

## Suggested slicer settings (Snapmaker Orca, U1, 0.4 mm nozzle, textured PEI)
- Layer height 0.20 mm, walls 3, top/bottom layers 0 / 6, infill 10% (walls dominate), no supports, no brim needed
- Wall generator Arachne; print upright as exported
- Multi-colour option: use the U1's 4 toolheads and change filament per cell height or per layer range
