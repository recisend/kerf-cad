# Honeycomb Desk Organizer (original design)

Original parametric design, built in Kerf CAD. Not based on any real product, brand or existing file
(Etsy requires 3D-printed items to be the seller's own original design).

## Why this design
Research (Snapmaker, JLC3DP, ZIK Analytics, Etsy creativity standards; mostly vendor blogs, so directional, not verified Etsy sales data):
desk organizers/accessories and geometric/parametric decor sell consistently; planters/vases sell weakly.

## Specs
- Size: 124.7 x 120 x 95 mm (fits Snapmaker U1 270 mm bed with large margin), 7 hex cells, staggered heights 95 / 75 / 55 mm
- Volume: ~128.8 cm3 (about 160 g PLA incl. infill)
- Walls 1.6 mm outer (4 x 0.4 mm lines), 3.2 mm shared walls, floor 2.4 mm (12 x 0.2 mm layers)
- No overhangs, no supports needed; flat base prints directly on the plate

## Snapmaker U1 / 0.4 mm nozzle suggested settings
- 0.4 mm nozzle, 0.20 mm layer height, 4 wall loops, 4 top/bottom layers (floor is 2.4 mm), 10-15% infill
- Supports: off. Brim: optional (small contact area is large, not needed)
- PLA ~ 210 C nozzle / 60 C bed. Silk or marble PLA looks good for listing photos.
