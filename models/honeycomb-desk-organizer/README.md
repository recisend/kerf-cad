# Honeycomb Desk Organizer

Original design (no branded/real-world product references). 7 hex cells, staggered heights 60/75/90 mm.

- Size: 100.8 x 97.0 x 90 mm (fits Snapmaker U1 270^3 bed), ~55 cm3 / ~68 g PLA
- Walls 1.6 mm (4 x 0.4 mm perimeters), floor 1.6 mm, all vertical walls: no supports, no overhangs
- Print flat on the bed, open side up. Suggested: 0.4 mm nozzle, 0.2 mm layers, 4 walls, 0% infill needed beyond 3 top/bottom layers, PLA 190-230 C, textured PEI 55-65 C
- Files: .3mf (print), .kerf.json (editable source), preview png in ../../examples
- Not published anywhere; listing is up to the owner.
