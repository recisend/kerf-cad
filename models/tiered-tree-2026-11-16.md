# Faceted Tiered Tree (2026-11-16)

Original geometric tabletop Christmas tree. Not based on any real item, brand or character.

**Why this one:** Etsy trend pages and seller guides this week list Christmas-themed spiral/tiered trees and holiday decor among the trending 3D prints (Nov = peak gift season). Sources were seller blogs, not hard sales data, so treat as directional.

## Print settings (Snapmaker U1, 0.4 mm nozzle)
- File: `tiered-tree-2026-11-16.3mf` (64 x 64 x 89 mm, fits the U1 bed easily; prints in the orientation exported, flat base on bed)
- Supports: none needed. Every underside is a 45 deg chamfer.
- Layer height 0.16-0.20 mm, line width 0.42 mm
- Walls: 1.6 mm shell = 4 perimeters of 0.4 mm. Top/bottom open cavity, so use 0% infill (or 5%).
- Volume ~19.5 cm3, about 24 g PLA.
- Tip: print in a single colour (PLA silk green/gold/white) or colour-change per tier. The U1 multi-toolhead setup lends itself to a different colour per tier, which makes a good listing photo.
