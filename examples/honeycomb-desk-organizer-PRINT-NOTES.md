## Snapmaker U1, 0.4 mm nozzle profile
- Size 102.3 x 103.6 x 90 mm (U1 bed 270 x 270 x 270, so it fits with a lot of room)
- Orientation: as exported, flat base down. No supports, no brim needed.
- Layer height 0.20 mm (0.16 mm for a nicer surface); line width 0.42-0.45 mm
- Walls: 1.6 mm = exactly 4 perimeters at 0.4 mm. Floor 2.0 mm = 10 layers at 0.2.
  Use 4 wall loops, 4-5 bottom layers. Infill is irrelevant (walls are fully solid); use 10-15% gyroid.
- Seam: set to "back" or aligned. Speed: outer wall 60-100 mm/s.
- Material: PLA / PLA+ (about 80 g estimated, ~65.8 cm3). PETG also fine.
- Colour idea: use the U1's multi-colour toolheads for a different colour per cup. Split by cup in the slicer.
