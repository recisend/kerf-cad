# Hex Succulent Planter Set (original design)

Two parts: hexagonal planter (80 x 69 x 70 mm) and matching drip saucer (90 x 78 x 10 mm).
Not based on any real product, brand or character.

## Snapmaker U1 / 0.4 mm nozzle settings
- Nozzle 0.4 mm, layer height 0.20 mm (0.16 mm for a nicer finish)
- Walls: 3 perimeters (planter wall is 2.0 mm = 5 lines at 0.4 mm; saucer rim is 3.0 mm)
- Top/bottom layers: 4 / 4, infill 10-15 % gyroid
- Supports: none needed (flat bottoms, vertical walls). Print planter upright, saucer flat.
- Both parts fit on one plate (X span about 173 mm, Y about 90 mm; U1 bed is 270 x 270 mm).
- Drain hole: 8 mm. Saucer clearance to planter: about 0.6 mm per side.
- Material: PLA / PETG; matte or silk colours photograph well.
