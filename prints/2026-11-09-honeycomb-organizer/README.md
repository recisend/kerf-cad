# Honeycomb Desk Organizer (original design, 2026-11-09)

Three fused hexagonal cups of different heights (100 / 80 / 62 mm) for pens, brushes and tools. Original geometry, not based on any real product, brand or character.

**Files:** `honeycomb-desk-organizer.3mf` (print file, mm), `honeycomb-desk-organizer.kerf.json` (editable Kerf source), `preview-top.png`, `../../examples/honeycomb-organizer.png`.

## Snapmaker U1 / 0.4 mm nozzle settings
| Item | Value | Why |
|---|---|---|
| Size | 88.5 x 89.6 x 100 mm | Fits the U1's 270 mm cube with wide margin; room to print several per plate |
| Walls | 1.6 mm = 4 perimeters at 0.4 mm | Exact multiple of line width, so no gap-fill artifacts |
| Floor | 2.4 mm = 12 layers at 0.2 mm | Solid and watertight |
| Layer height | 0.2 mm (0.16 mm for a finer finish) | Standard 0.4 mm nozzle quality |
| Perimeters | 4, top/bottom layers 5 | Walls are the structure; no infill needed (walls are fully solid) |
| Infill | 10 to 15% gyroid | Only the floor uses it |
| Supports | None | All walls vertical, floor flat, no overhangs |
| Orientation | As exported (open end up, flat base on bed) | 0.6 mm base chamfer reduces elephant's foot |
| Material | PLA (about 75 g, about 60.7 cm3) | Also fine in PETG |
| Brim | Not needed; 3 mm brim optional for the tall cup | Large flat footprint |

The model is not centred on the bed; the slicer will centre it. Estimated print time is not computed here. Slice it in Snapmaker Orca to get a real figure before pricing.
