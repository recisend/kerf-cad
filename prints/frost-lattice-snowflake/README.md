## Snapmaker U1 settings (0.4 mm nozzle)
- Build volume 270 x 270 x 270 mm. This model fits easily, and about 6 fit on one plate (arrange in the slicer).
- Layer height 0.20 mm (15 layers). Use 0.12 mm for finer tips.
- Walls: 3 (1.2 mm). Top/bottom layers: 4/4 (0.8 mm). Infill 15%. A 3 mm part is nearly solid anyway.
- Supports: none. Brim: none, or 3 mm if lifting.
- Thinnest features: about 4 mm branches, so 0.4 mm lines are fine.
- Print flat as exported. Use white or a pearlescent PLA.
- Multi-colour: the U1's 4 toolheads could do a two-colour hub if you split the part in the slicer.
