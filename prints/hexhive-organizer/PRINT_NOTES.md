# HexHive Desk Organizer — print notes & DRAFT listing (NOT published)

Original honeycomb pen/tool organizer. 7 hex cells, stepped heights (100 / 80 / 60 mm).
Footprint ~94 x 91 mm, height 100 mm. No branded or real-product shapes.

## Designed for Snapmaker U1, 0.4 mm nozzle (270^3 mm bed)
- Cell walls 1.2 mm (3 x 0.4 perimeters), outer walls 1.6 mm (4 perimeters), floor 1.6 mm (8 x 0.2 layers).
- Vertical walls only: no supports, no overhangs, no bridges. Flat base.
- Print upright, no rotation. Suggested: 0.2 mm layer, Arachne walls, 2-3 top layers, 10-15% infill (walls carry the part), brim optional.
- The 3MF contains geometry only (mm). It carries no slicer profile; select the U1 / 0.4 nozzle profile in Snapmaker Orca.
- Material: PLA/PETG; works in any colour (or colour-change at layer heights for a gradient look).
