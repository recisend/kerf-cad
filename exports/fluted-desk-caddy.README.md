# Fluted Desk Caddy (original design, 2026-11-27)

Original, non-branded design: ribbed/fluted desk organizer with a pen cup, a narrow card/phone slot and a tray.
Ribbed/fluted desk organizers and pen holders are an actively listed Etsy category (typically ~$13-25); gift-positioned.
Trend sources were vendor blogs and Etsy listing snapshots, not Etsy sales data, so treat "trending" as directional.

## Print settings (Snapmaker U1, 0.4 mm nozzle)
- Model: 120 x 70 x 90 mm (fits the U1 270 mm build volume), flat bottom, no supports needed, no overhangs.
- Layer height 0.20 mm, line width 0.42 mm, walls 3 (1.26 mm), top/bottom 4 layers, infill 10-15% gyroid.
- Flutes are 6 mm wide / 1.5 mm deep, printable as-is. Wall around cavities is 4-8 mm.
- Material: PLA or PETG. Print time/filament: check in Snapmaker Orca after slicing.
